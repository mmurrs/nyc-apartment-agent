§ 03

Call this API

One line · Any agent
Terminal · AgentCash
$npx agentcash add your-origin

Registers this origin with AgentCash so any agent with a funded wallet can hit the paid routes over x402 or MPP. Or bring your own client: @x402/fetch, mppx, or raw HTTP with a payment header.

How payment works

Client hits a route. Server returns 402 with a price quote. Client attaches USDC payment; the server verifies it, settles, and returns the result — all on the same round trip.

  • x402 · USDC on Base
  • MPP · USDC on Tempo
  • Settled in one round trip
  • No account, no key, no form
